# Cognitive Care App

This package is a mobile-friendly Progressive Web App and Capacitor-ready project.

## Fastest way to use it
Deploy the project on HTTPS (for example GitHub Pages, Netlify or Vercel), then open it on a phone and choose **Add to Home Screen / Install app**.

## Native Android/iOS packaging
Install Node.js, then run:
npm install
npx cap add android
npx cap add ios
npm run sync

Then open the native project in Android Studio or Xcode.

Note: this environment cannot download npm/Android build dependencies, so the ZIP contains the ready web app and Capacitor configuration rather than a compiled APK.
